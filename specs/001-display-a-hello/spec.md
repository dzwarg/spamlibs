### Primary User Story
As a user, I want to be able to visit a page that displays the text "hello world" so that I can confirm the application is running.

### Acceptance Scenarios
1. **Given** a running application, **When** a user navigates to the "hello world" page, **Then** the page displays the text "hello world".
